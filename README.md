# 诗词闯关 · 微信小程序

唐诗宋词补全闯关。15 句一局，12 秒限时，连击加分，六档称号（白丁 → 状元）。
纯前端、无后端、无支付，题目全部取自公版名篇，个人主体可直接提审。

## 一、导入与运行

1. 打开「微信开发者工具」，选择「导入项目」；
2. 目录指向本文件夹（含 `app.json` 的那一层）；
3. AppID 选「测试号」即可先跑起来；正式提审时换成你自己的 AppID；
4. 点「预览」扫码，手机上即可玩。

`project.config.json` 里已把 `appid` 设为 `touristappid`（测试号），`urlCheck` 已关闭。

## 二、目录结构

```
app.js                 全局逻辑：最高分与最佳称号存本地
app.json               页面注册、窗口样式
app.wxss               全部页面样式（纸色 + 朱红，宋体）
project.config.json    开发者工具项目配置
sitemap.json           搜索索引规则

pages/index/           首页：标题、最高分、开始、邀请、规则
pages/play/            答题页：计时条、选项、对错反馈、原文解析
pages/result/          结算页：称号、得分、统计、再来一局、分享

utils/bank.js          题库（85 句，含出处与全文）
```

## 三、玩法参数

| 项目 | 值 |
| --- | --- |
| 每局题数 | 15（从 85 句题库随机抽取） |
| 单题限时 | 12 秒，剩 3 秒变红 |
| 答对得分 | 10 + 连击加成（每次 +2，封顶 5 次）+ 剩余秒数 |
| 答错/超时 | 连击清零，展示正确答案与全文 |
| 称号 | 15 状元 / 13–14 进士 / 11–12 举人 / 8–10 秀才 / 5–7 童生 / 0–4 白丁 |

改题数或时长：`pages/play/play.js` 顶部的 `TOTAL` 与 `LIMIT`。
加题目：往 `utils/bank.js` 追加，格式见文件内注释，`＿` 为挖空位。

## 四、上架流程（个人主体）

1. **注册小程序**：mp.weixin.qq.com → 立即注册 → 小程序 → 个人主体，需一个未注册过公众平台的邮箱，管理员微信扫码。
2. **填写基本信息**：名称、图标、简介。名称建议「诗词闯关」这类不易重名的，重名会被驳回。
3. **小程序备案**：设置 → 小程序备案，上传身份证 + 人脸核验，平台初审 1–2 个工作日，之后工信部短信（12381）核验，24 小时内完成，再经通管局审核。**未备案无法上架**，整体约 1–3 周，个人主体最多备案 5 个小程序。
4. **选服务类目**：建议「教育 > 教育信息服务」（个人主体可选、无需额外资质）。不要选「游戏」相关类目——那属于小游戏体系，需要软件著作权。
5. **上传代码**：开发者工具右上角「上传」→ 填版本号与备注。
6. **提交审核 → 发布**：后台「版本管理」里提交，通常 1–3 天出结果。

参考文档：

- 小游戏类目与资质：https://developers.weixin.qq.com/minigame/introduction/guide/type.html
- 小程序备案指引：https://developers.weixin.qq.com/miniprogram/product/record/record_guidelines.html
- 备案常见问题：https://developers.weixin.qq.com/miniprogram/product/record/record_faq.html

## 五、关于「小游戏」路线（可选）

如果你希望它出现在微信「小游戏」入口、或以后接入激励视频广告分成，需要走小游戏体系：

- 个人主体可发布小游戏，需提交《计算机软件著作权登记证书》+《游戏自审自查报告》，个人主体可免版号；
- 但个人主体**不能选**「文化互动」「角色类」「牌类」三类，诗词类容易被判为文化互动，存在风险；
- 小游戏账号的一级类目注册时勾选后**不可修改**，选错只能重新注册。

所以本仓库采用「小程序 + 教育类目」路线：无需软著、类目可控、当天可提审，代价是不出现在小游戏入口、不能接广告分成。
